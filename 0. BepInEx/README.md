# BepInEx  ➠  [![](/dlicon.svg) BepInEx_win_x64_5.4.23.3.zip](<https://raw.githubusercontent.com/RaulCotar/gloomwood-mods/refs/heads/master/0. BepInEx/BepInEx_win_x64_5.4.23.3.zip>)

This plugin/modding framework is a prerequisite for the other mods.  
Just download and unzip it in the game folder (the folder that contains `Gloomwood.exe`).

> [!NOTE]
> Since there is no native Linux build of Gloomwood, Linux users also need to use the same Windows files.
